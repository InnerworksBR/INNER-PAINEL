# Decisões

## D-001 — Não bloquear servidores Windows

**Status:** proposta para aprovação.  
SNMP/Hyper-V são marco posterior; seus stubs serão explicitamente marcados como não concluídos até esta implementação.

## D-002 — Habilitação por capability

**Status:** proposta para aprovação.  
Collectors avançados ficam desabilitados sem suporte/configuração válida e não degradam o agente base.

## D-003 — Varredura somente autorizada

**Status:** obrigatória.  
Discovery aceita apenas ranges cadastrados para a empresa/site, com limite de tamanho e concorrência.
